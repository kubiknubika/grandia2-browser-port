# Grandia 2 Browser Port

Браузерный порт Grandia 2 на чистом JavaScript.

**Играть:** https://kubiknubika.github.io/grandia2-browser-port/

## Стек
- Canvas API
- Gamepad API (DualShock 3)
- GitHub Pages
